# Wobble Heads

Browser sandbox for bobble-head characters that walk, jump, and trip when the head wobbles too much.

Open `prototype/index.html` in a browser (serve the folder over http so models load).

- **WASD** walk, or drive once you are in a car
- **E** walk up to a car, sit down with a human get-in motion, then climb out the same way
- **Space** jump
- Drag to look, scroll to zoom
- Heads only nudge while walking and go still when you stop

This is an early playable sketch (Three.js + Mixamo-style glTF). The later game path is Vite + TypeScript + Rapier.
